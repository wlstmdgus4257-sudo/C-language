3번. 문자열 연결
다음 프로그램을 실행했을 때 출력되는 내용은?

#include <stdio.h>
#include <string.h>

int main(void) {
    char str[20] = "C";
    strcat(str, "Lang");
    printf("%s", str);
    return 0;
}

① C Lang
② Lang
③ C
④ CLang

4번. 구조체 포인터
다음 코드를 실행한 뒤 포인터 p를 이용해 구조체 멤버 score에 접근하는 올바른 표현은?
struct Student {
    int score;
};

struct Student s = {90};
struct Student *p = &s;


① p->score
② p.score
③ *p.score
④ p-score
